# .github

Org-wide GitHub configuration and community health files for [DigitalReef-NZ](https://github.com/DigitalReef-NZ).

This repository holds shared defaults that GitHub applies across the organisation. It is not a product repository.

## Contents

| File | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | Rendered as the organisation landing page at [github.com/DigitalReef-NZ](https://github.com/DigitalReef-NZ). |
| [`SECURITY.md`](SECURITY.md) | Responsible disclosure contacts and response timelines. |
| [`CODEOWNERS`](CODEOWNERS) | Default reviewer routing for this repository. |
| [`LICENSE`](LICENSE) | Proprietary licence. Source is publicly readable; reuse requires written permission. |
| [`CHANGELOG.md`](CHANGELOG.md) | History of changes to org-wide defaults. |
| `.gitattributes`, `.gitignore` | Repository hygiene. |

## About Digital Reef

Digital Reef is shared civic technology infrastructure for recreation, environmental stewardship, and community well-being organisations in Aotearoa New Zealand. See the [organisation profile](https://github.com/DigitalReef-NZ) or [digitalreef.nz](https://www.digitalreef.nz) for an overview of what we do.

## Security

Please report vulnerabilities privately. See [`SECURITY.md`](SECURITY.md) for contacts and expectations. Do not open public issues for security concerns.

## Contributions

This repository accepts contributions from Digital Reef maintainers only. External pull requests will be closed without review. For enquiries or collaboration proposals, contact **shayne@digitalreef.nz**.
